This module offers practical skills as well as understanding of the underlying principles of
programming the World Wide Web. There are two hours of lectures per week and weekly timetabled lab
sessions. Major topics include Internet and Web-server basics; client-side programming using XHTML;
Cascading Style Sheets and JavaScript. Students develop practical skills in server-side programming
using PHP and gain hands-on experience with the practical issues involved in setting up a website.
